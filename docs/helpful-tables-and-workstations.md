# Helpful tables and workstations

This is a practical guide to the useful table-like blocks in the installed modpack: tables, benches, stations, furnaces, anvils, and similar work blocks. It does not list decorative furniture tables, which have no special use beyond building.

If the block you remember sounded like "stone hinder," it is probably the **Bench Saw**, the name currently shown for the vanilla **Stonecutter** in the pack. It cuts stone blocks into their slab, stair, wall, and other building variants without a crafting grid.

## Tinkers' Construct tables

The installed **Tinkers' Construct 3.10.2.92** mod has its own tool-building chain. A **Pattern** is an item, not a table. The **Part Chest**, **Tinker's Chest**, and **Cast Chest** are storage blocks, not workstations.

## The useful starting set

For a first Tinkers' tool, make these in order:

1. **Patterns**: craft from planks and sticks. They are the reusable instructions for choosing a tool part shape.
2. **Part Builder**: use a pattern to choose a part, add a shapeable material, then take the part. The installed guide specifically calls out soft materials that can be shaped by hand. It can also reshape a soft part. Materials marked as not shapeable must be made by casting instead.
3. **Tinker Station**: combine the required parts into a basic tool, repair it, replace parts, and apply most modifiers. Select a tool layout on the left, then fill its part slots. The station can handle at most three components, so it cannot make broad tools.

The three work blocks above are the best early-game use of the mod. Keep several patterns around, since the Part Builder, Tinker Station, and the storage blocks all use them in their recipes.

## Every Tinkers' Construct workstation

| Block | What it does | Prerequisites and best use |
| --- | --- | --- |
| **Crafting Station** | A crafting table with an inventory that keeps its crafting grid contents when closed. | Craft a normal workbench plus one Pattern. Use it as the base crafting table for the Tinkers area, especially when a recipe needs several steps. |
| **Part Builder** | Turns a selected Pattern and a shapeable material into a tool part. | Requires two Patterns and planks. This is the beginning of hand-made tool parts, such as early wooden or stone parts. |
| **Tinker Station** | Builds basic tools, repairs them, swaps parts, and applies most modifiers. | Requires three Patterns and planks. Bring the exact parts selected by the tool layout. It supports up to three parts. |
| **Tinker's Anvil** | The larger tool-building station. | Requires an anvil metal and either seared Smeltery blocks or scorched Foundry blocks. Use it for broad tools and any tool with four or five parts, or when changing parts on one of those tools. |
| **Tool Forge** | The named upgrade form of a Tinker's Anvil, built around a Tinker Station. It fills the same large-tool role. | Requires an existing Tinker Station, anvil metal, and either seared or scorched blocks. The installed recipes produce the corresponding anvil block with the Tool Forge name, so it is not another station that needs to sit beside an anvil. |
| **Modifier Worktable** | Fine-tunes modifiers already on a tool. It can sort modifiers, toggle certain modifier effects, hide or reveal modifier text with ink, and remove applicable modifiers using the matching ingredients. | Requires natural workstation stone and seared blocks. Put the tool in first, then use the recipes shown for its applicable modifiers. This is for adjustment, not normal tool assembly. |
| **Seared Casting Table** | Casts a single item or tool part from molten fluid supplied by a faucet. | Requires seared bricks and a basic melting setup: a Melter, fuel source or tank, Seared Faucet, and molten material. Use it for metal tool parts, ingots, and reusable gold casts. |
| **Scorched Casting Table** | The Foundry version of the Casting Table. | Requires scorched bricks and a Foundry. Unlike the seared version, it needs a cast or Gold Bars acting as an empty cast before pouring. Use it with the higher-tier Foundry setup. |

## The support blocks that are easy to mistake for tables

| Block | What it is useful for | Prerequisite |
| --- | --- | --- |
| **Part Chest** | Holds up to 256 different tool-part types. Use it beside the Part Builder and Tinker Station to organize heads, handles, bindings, and other parts. | A wooden chest, one Pattern, planks, and sticks. |
| **Tinker's Chest** | Holds up to 64 stacks, with 16 items per stack. It can be dyed. Good for keeping patterns, modifier ingredients, and small Tinkers supplies together. | A wooden chest, one Pattern, planks, and lapis. |
| **Cast Chest** | Stores the relevant casts for casting work. | A wooden chest, seared bricks, and a gold cast. It is a later-game convenience for a casting area. |

## Casting without guesswork

The Part Builder is deliberately not the answer for every material. For materials that must be cast, put the part shape in a Casting Table and pour molten material through a faucet.

There are two important cast types:

- **Gold cast:** pour one ingot of molten gold over an existing tool part in a Casting Table. The original part is consumed, but the resulting gold cast is reusable. Make these for parts you expect to produce repeatedly.
- **Sand cast:** place a blank sand cast in the Casting Table, press it with an existing tool part, remove the part, then pour the molten material. The shaped sand cast is consumed when used and becomes blank again if picked up. It is useful before spending gold.

For a large output such as a block, use the matching **Casting Basin**, not a Casting Table. It is part of the same melting and faucet system but is not a table.

## A practical progression

Start with a Crafting Station, Patterns, a Part Builder, and a Tinker Station. Make a basic tool from the station's selected parts, then return there to repair it with a valid repair material, change a part, or add normal modifiers.

Next, build a Melter and casting setup. Casting unlocks tool parts that cannot be shaped by hand and lets you make reusable gold casts. Build a Tinker's Anvil or Tool Forge when you want broad tools. Add the Modifier Worktable once you begin refining an established tool rather than simply building it.

The in-game recipe viewer remains the final authority for exact materials, because a tool's required parts and a modifier's ingredients depend on the selected recipe. In the viewer, click a tool or part and use its recipe view to see the current layout and compatible materials.

## Tables that are only furniture

The pack also includes many named tables and benches from Cozy Home and Builder's Addition, in every wood type, plus bedside tables and stump tables. Those are decorative. They are intentionally not listed one by one because they do not provide a special crafting or processing function.

## Fast way to identify an unfamiliar block

1. Hover the block in the inventory and read the mod name at the bottom of its tooltip.
2. Use the recipe key to see how to make it, then the recipe-use key to see what it is used for.
3. If its use view is empty and the block is from Cozy Home or Builder's Addition, it is almost certainly furniture.
4. For a block you found in the world, use the same lookup after picking it up or searching its displayed name.
