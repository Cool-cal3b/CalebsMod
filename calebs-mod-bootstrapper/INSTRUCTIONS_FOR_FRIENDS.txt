🎮 CALEB'S MOD - INSTALLATION INSTRUCTIONS 🎮

Hey! Here's how to install and play.
Jump to the section for your computer: WINDOWS or MAC.


═══════════════════════════════════════════════════════════
  WINDOWS
═══════════════════════════════════════════════════════════

1️⃣ DOWNLOAD
   - Save the CalebsModBootstrapper.exe file I sent you

2️⃣ RUN IT
   - Double-click the CalebsModBootstrapper.exe file
   - If Windows shows a security warning, click "More info" then "Run anyway"
     (It's safe, Windows just doesn't recognize it because it's not signed)

3️⃣ WAIT
   - The first time will download the game client (takes a few minutes)
   - You'll see progress updates in the window

4️⃣ PLAY!
   - The game will launch automatically when ready
   - Next time you run the bootstrapper, it will auto-update if needed

📍 WHERE ARE THE FILES?
The game installs to: %LOCALAPPDATA%\CalebsMod\
(You can paste that into Windows Explorer to see the files)

⚠️ TROUBLESHOOTING:

"My antivirus blocked it!"
→ Add an exception for CalebsModBootstrapper.exe
→ It's safe, I promise! Your antivirus is just being cautious

"Nothing is happening!"
→ Make sure you have a good internet connection
→ Try running as administrator (right-click → Run as administrator)

1️⃣ DOWNLOAD

📍 WHERE ARE THE FILES?
   - The app:   ~/Applications/CalebsModClient.app

   (In Finder, press Cmd+Shift+G and paste one of those paths)

⚠️ MACOS SAYS IT'S BLOCKED

You'll see something like "Apple could not verify CalebsMod Installer is free
of malware" or "cannot be opened because it is from an unidentified developer".

This is just because I haven't paid Apple $99/year for a developer
certificate. Here's how to get past it - you only do this once:

   1. Try to open the app (double-click it). Let it get blocked.
   2. Open System Settings (the gear icon)
   3. Click "Privacy & Security" in the sidebar
   4. Scroll down - near the bottom you'll see a message about
      "CalebsMod Installer was blocked"
   5. Click "Open Anyway" next to it
   6. Enter your password / Touch ID if asked
   7. Double-click the app again - it opens this time

   On older macOS versions you can instead right-click the app and
   choose "Open", then click "Open" in the dialog.

STILL BLOCKED? There's a backup way in that macOS never blocks:
   - In the same folder, double-click "Run in Terminal.command" instead
   - If THAT gets blocked too, open Terminal (Cmd+Space, type "Terminal")
     and drag "Run in Terminal.command" into the window, then press Enter

LAST RESORT: open Terminal and run this, then try again:
     xattr -dr com.apple.quarantine ~/Downloads/"CalebsMod Installer (Mac)"

⚠️ OTHER MAC TROUBLESHOOTING:

"It opened Terminal but nothing happened"

→ Check your internet connection

"I don't see the app in Spotlight"
→ It's at ~/Applications/CalebsModClient.app - try opening that directly
→ Spotlight can take a minute to index a newly installed app
