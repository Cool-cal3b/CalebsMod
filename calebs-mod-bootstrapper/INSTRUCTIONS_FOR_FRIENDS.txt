🎮 CALEB'S MOD - INSTALLATION INSTRUCTIONS 🎮

Hey! Here's how to install and play:

1️⃣ DOWNLOAD
   - Save the CalebsModBootstrapper.exe file I sent you

2️⃣ RUN IT
   - Double-click the CalebsModBootstrapper.exe file
   - If Windows shows a security warning, click "More info" then "Run anyway"
     (It's safe, Windows just doesn't recognize it because it's not signed)

   - You'll see progress updates in the window

4️⃣ PLAY!

   - Next time you run the bootstrapper, it will auto-update if needed
