# All Worlds and Dimensions

This is the starting point for the server's worlds. Each major dimension has
its own guide so details can be updated without repeating them here. Installed
mod facts were checked against the local `unzipped-mods/` cache. The current
world save also contains folders for every modded dimension listed below.

## How many worlds are there?

There are **3 vanilla dimensions**, **4 conventional modded dimensions**, and
**4 DimensionalDoors dimension spaces**.

That gives the server **11 registered dimension IDs in total**. The useful
adventure count is lower because the four DimensionalDoors IDs hold Limbo and
many isolated pocket rooms rather than four continuous open worlds.

## What changes the Nether and End?

The **Nether** receives the larger environmental overhaul. Regions Unexplored
adds five biomes, while several mods add ruins, dungeons, traps, floating
islands, creatures, ores, and lava fishing. See the [Nether guide](nether.md)
for the installed additions.

The **End** keeps its vanilla biome layout but has more destinations. Its main
additions are Enderslime Islands, End ruins, an End Gate Fortress, oases,
geodes, fishing, and smaller structures. See the [End guide](end.md).

## World-generation warning

Terrain features normally appear only in chunks generated after the relevant
mod was installed. If a structure or biome seems absent near familiar areas,
travel into unexplored territory before assuming it is disabled.
