# Capsule structures

Capsules are portable structure kits. This server's Capsule mod can add a reward capsule to loot chests in structures such as mineshafts, dungeons, temples, villages, shipwrecks, bastions, end cities, and woodland mansions.

The structure names shown in a capsule's tooltip correspond to the entries below. The size is the template's reserved bounding box, written as `width x height x depth` in blocks. Leave that entire volume clear before deploying it. Some templates include air around the build, so the finished visible structure can be smaller than the listed box.

## Using a reward capsule

1. Hold the capsule and right-click to activate its placement preview.
2. Aim at a clear, level location and right-click again to deploy it. A one-use capsule is consumed after deployment.
3. Left-click while holding the capsule to rotate the preview. Sneak and left-click to mirror it.

Loot rewards that contain no entities may be reusable blueprints. A blueprint takes the required blocks from a linked inventory, or from the player's inventory when needed. Sneak and right-click an inventory to link it.

## Capturing your own builds

An empty capsule can also carry your own build. Place a Capture Base beneath the desired area, hold an empty capsule to see the capture preview, then use the capsule on the Capture Base to pack the supported blocks into it. Do not rely on this for every machine or special block: the server excludes spawners, bedrock, end portals, player graves, and several modded machine types from ordinary captures.
