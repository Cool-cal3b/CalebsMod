# The Cave Stuff Dimension

Back to the [all-worlds index](all-worlds.md).

**Cave Stuff 1.06.06** registers a world internally named `testing`. Despite
that unfinished-sounding name, the installed cache contains a complete cave
dimension definition and the current server world has created its dimension
folder.

## What is there?

The generator mixes four cave environments:

- **Glowworm Caves**, with Glowworm materials and creatures
- **Guano Caves**, with Guano blocks, creatures, altars, and equipment
- Vanilla-style Lush Caves
- Vanilla-style Dripstone Caves

Confirmed creatures and systems include adult and infected Glowworms, Guano
Golems, the Guano Guardian, Guano altars, Guano weapons, and Glowworm building
materials.

## Entering

The installed item list includes a **Testing Portal Igniter**, and the mod
registers a corresponding portal block and portal shape. Use the recipe viewer
for the exact current ingredients because no ordinary JSON crafting recipe for
the igniter is present in the extracted cache.

## Travel advice

Bring abundant light, food, blocks, and a dependable weapon. This is a closed
cave world with hostile creatures and vertical terrain, so marking the portal
and nearby junctions is more important than it is in an open-sky dimension.

The installed dimension ID is `cave_stuff:testing`.
