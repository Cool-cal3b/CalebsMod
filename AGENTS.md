## Documentation requirements

Create documentation only when requested. Write it as a brief, informative guide
for the server's friends, addressing the reader generally rather than Caleb
personally. Never use em dashes in documentation. Base installed-mod facts on
the local `unzipped-mods/` cache, and clearly distinguish anything not verified
there.
